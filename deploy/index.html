Sudoku Solver

画像を選択すると自動で盤面を読み込み、解法を計算して回答を表示します。
誤認識があった場合はクリックして手動で修正してください。

About

Browser-only Sudoku OCR + solver.

  • No server-side Python required.
  • Image upload auto-parses Sudoku board in browser.
  • Solve steps with previous/next navigation.
  • Reset returns to the uploaded initial board.
  • Answer button shows full solved board.

Tech

  • OpenCV.js for perspective transform and cell extraction
  • Tesseract.js for digit OCR
  • Plain JavaScript backtracking solver
